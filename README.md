# 风格图谱 Style Atlas

> AI 创作风格参考：102 条画面 / 镜头 / 叙事 / 音乐 / 博主风格词条，中英双语提示词，免费复制。
> A curated, bilingual library of 102 AI style prompts — visual, camera, narrative, music & creator styles.

🌐 **在线访问 / Live**

- 国内：[styleatlas-gallery.cn](https://styleatlas-gallery.cn)
- 海外：[style-atlas.n-ai-gallery.workers.dev](https://style-atlas.n-ai-gallery.workers.dev)

## 每条词条给你什么 / What's in an entry

- 🎨 AI 生成示例图/视频（素材为 AI 生成的风格示意）
- 📋 英文提示词 + 负面提示词 + 中文关键词，一键复制
- 🔗 「相近 →」指路：找到下一个想要的感觉
- 🧩 「拼搭」：跨模块组合多种风格，一次拿走整条 prompt
- 🔥 本周热门：浏览/复制/分享行为实时排行
- ↗️ 词条分享：复制深链接，对方打开自动定位高亮

## 技术栈 / Stack

React 18 · TypeScript · Vite · 双站部署（腾讯云 EdgeOne Pages + Cloudflare Workers）· EdgeOne Pages Functions + KV（热度计数）· 百度统计
